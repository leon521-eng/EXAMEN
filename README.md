El proyecto esta desarrollado en python, por lo que no requiere compilación previa.

### Prerrequisitos
- Tener insalado **Python 3.6** o una versión superior.
- No tener librerias de terceros (el proyecto solo usa las librerias estándar de Python).

### Pasos para ejzecutar el programa 
1. Abrir la terminal.
2. Navegar al directorio donde se encuentra el archivo con eñl código fuente utilizando `cd`. Por ejemplo:

```bash
cd /ruta/a/tu/directorio/Proyectos/Examen
```

3. Ejecutar el script principal invocando el intérprete de Python:

```bash
python3 Musica.py
```

(Nota dependiendo de tu sistema operativo, el comando podría ser simplemente **python** o **py**).
